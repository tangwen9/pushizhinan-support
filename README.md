## 常见问题

### Q：AI 助手提示「网络错误，请检查连接后重试」？
A：AI 对话和拍照翻译需要联网，本地核心功能（菜品图鉴、对照、海报）完全离线可用。请检查 WiFi 或蜂窝数据连接。

### Q：如何升级 Pro 解锁全部 AI 功能？
A：进入「我」标签页，点击「升级 Pro 解锁全部 AI 功能」按钮，跳转 Apple 支付。¥18 一次性买断，永久使用，购买同步至所有同 Apple ID 设备。

### Q：购买后换手机功能不见了？
A：在新设备的「我」页点「升级 Pro」按钮 → 进入付费页 → 点「恢复购买」，会自动同步你之前的购买记录（同 Apple ID）。

### Q：免费版有什么限制？
A：免费版可使用所有菜品图鉴、味觉对照、点餐短语、打卡、海报、红酒推荐等核心功能。AI 对话每天 3 次免费、拍照翻译每天 1 次免费。Pro 用户无限。

### Q：拍照翻译的图片会被保存吗？
A：用户拍摄的图像会通过我们的代理服务器转发给阿里云通义千问大模型处理，**不会被存储**。详情见 [隐私政策][1]。

### Q：AI 推荐的菜品和餐厅准确吗？
A：AI 回复及菜单翻译仅供参考，请以餐厅实际菜单和服务员说明为准。如遇饮食禁忌，请务必当面与餐厅确认。
